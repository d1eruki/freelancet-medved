# Сайт «МЁДВЕДЬ»

Исходный код новой версии сайта петербургского производителя мида, сидра и пуаре «МЁДВЕДЬ». Сайт знакомит с напитками, производством и компанией, показывает партнёров и содержит контакты для покупателей и оптовых клиентов.

## Что реализовано

- Главная страница с обзором продукции и компании.
- Каталог и отдельные страницы категорий: мид, сидр и пуаре.
- Страницы о компании, производстве, партнёрах и контактах.
- Страница HoReCa с ассортиментом, форматами тары, географией поставок и обращением в отдел продаж.
- Политика конфиденциальности и страница ограничения ответственности.
- Подтверждение возраста посетителя с сохранением выбора в браузере.
- Плавная прокрутка всех страниц через Lenis; анимация отключается при системной настройке «уменьшить движение».

Страницы и данные каталога находятся в репозитории. Сборка заранее создаёт HTML для каждого адреса из [структуры сайта](docs/site-structure.md), а браузер подключает интерактивность через Vue 3. Форма обратной связи обрабатывается PHP на хостинге; CMS нет.

## Локальный запуск

Для сборки в GitHub Actions используется Node.js 24. Установите зависимости и запустите сервер разработки:

```bash
npm ci
npm run dev
```

Для проверки собранной версии:

```bash
npm run build
npm test
npm run preview
```

Для локальной проверки обработчика формы нужен PHP CLI:

```bash
php -l public/api/contact.php
npm run test:api
```

Тесты запускают временный PHP-сервер и подменяют системную отправку почты: настоящие письма не отправляются. Запускать PHP как фоновый сервис не требуется.

Форма принимает одну корректно заполненную попытку за 10 секунд с одного IP, независимо от cookies; пользователи общего Wi-Fi делят этот лимит. Попытка учитывается до обращения к почте, включая ошибки отправки. Хеши IP и время попыток хранятся в `.medved-contact-rate-limit.json` рядом с `public_html`, вне публичного каталога; истёкшие записи удаляются при следующей попытке. PHP должен иметь права создавать и изменять этот файл (режим `600`). Если хранилище недоступно, API возвращает `503` и пишет причину в журнал PHP; предупреждения не попадают в JSON. Таймаут браузера — 15 секунд, он не отменяет уже начавшуюся серверную отправку.

Готовые файлы появляются в `dist/`. По умолчанию сборка использует базовый путь `/freelancet-medved/`; для размещения в корне домена задайте `SITE_BASE=/ npm run build`. На хостинге должны работать PHP и правила Apache из `public/.htaccess`.

Изменения сначала публикуются из `develop` на `https://test.medved.beer/`, затем после проверки переносятся через pull request в `main` для публикации на основном сайте. Для локальной проверки тестового окружения используйте `SITE_BASE=/ SITE_ENV=staging npm run build` и `SITE_ENV=staging npm test`. Настройка каталогов, запрет индексации и порядок проверки описаны в [инструкции по публикации](docs/deployment.md).

При сборке PNG и JPEG, импортируемые из `src/assets/`, преобразуются в WebP, если результат меньше исходного файла. Исходные изображения не меняются; SVG и файлы из `public/` не обрабатываются.

## Структура репозитория

- `src/components/` — общие элементы интерфейса; страницы и их собственные компоненты сгруппированы в каталогах `home/`, `about/`, `catalog/`, `category/`, `contacts/`, `partners/`, `production/`, `horeca/`, `legal/` и `not-found/`. Компоненты, используемые на нескольких страницах, остаются в корне `src/components/`.
- `src/data/` — каталог, маршруты, навигация, партнёры и тексты юридических страниц.
- `src/assets/` — изображения, логотипы и шрифты.
- `src/styles/` — общие стили.
- `scripts/` — генерация страниц и проверки; `scripts/vite/` — обработка изображений при сборке.
- `docs/` — материалы о структуре, дизайне и плане работ.

Сайт собирается с помощью Vite, а стили используют Tailwind CSS. Настройки базового пути и подключение плагинов находятся в `vite.config.js`.
