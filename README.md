# Сайт «МЁДВЕДЬ»

Исходный код новой версии сайта петербургского производителя медовухи, сидра и пуаре «МЁДВЕДЬ». Сайт знакомит с напитками, производством и компанией, показывает партнёров и содержит контакты для покупателей и оптовых клиентов.

## Что реализовано

- Главная страница с обзором продукции и компании.
- Каталог и отдельные страницы категорий: медовуха, сидр и пуаре.
- Страницы о компании, производстве, партнёрах и контактах.
- Политика конфиденциальности и страница ограничения ответственности.
- Подтверждение возраста посетителя с сохранением выбора в браузере.

Это клиентское приложение на Vue 3. Страницы и данные каталога находятся в репозитории; CMS и серверной части в этой реализации нет. [Структура сайта](docs/site-structure.md) и [техническое задание](docs/technical-specification.md) описывают полный объём проекта, включая страницы, которых пока нет в коде.

## Локальный запуск

Для сборки в GitHub Actions используется Node.js 24. Установите зависимости и запустите сервер разработки:

```bash
npm ci
npm run dev
```

Для проверки собранной версии:

```bash
npm run build
npm run preview
```

Готовые файлы появляются в `dist/`. По умолчанию сборка использует базовый путь `/freelancet-medved/`; для размещения в корне домена задайте `SITE_BASE=/ npm run build`.

При сборке PNG и JPEG, импортируемые из `src/assets/`, преобразуются в WebP, если результат меньше исходного файла. Исходные изображения не меняются; SVG и файлы из `public/` не обрабатываются.

## Структура репозитория

- `src/components/` — страницы и повторно используемые элементы интерфейса.
- `src/data/` — каталог, навигация, партнёры и тексты юридических страниц.
- `src/assets/` — изображения, логотипы и шрифты.
- `src/styles/` — общие стили.
- `scripts/vite/` — обработка изображений при сборке.
- `docs/` — материалы о структуре, дизайне и плане работ.

Сайт собирается с помощью Vite, а стили используют Tailwind CSS. Настройки базового пути и подключение плагинов находятся в `vite.config.js`.
