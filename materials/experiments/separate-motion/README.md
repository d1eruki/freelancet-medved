# Раздельное движение

Снимок реализации с четырьмя слоями на напиток: стакан, банка и две тени. Стакан движется первым, банка и её тень — с задержкой 100 мс. Все 12 WebP и связанные компоненты, данные, сцена и экспортёр сохранены с исходной структурой путей.

Архив не подключён к сайту. Это снимок частей проекта, а не отдельное приложение: ему нужны общие модели, оптика, рецепты и зависимости основного репозитория.

Для восстановления сначала сохраните текущие совместные рендеры и код. Затем скопируйте `src/` и `scripts/render-product-slider.mjs` из этой папки в одноимённые пути корня проекта. Изменения проверок нужно адаптировать обратно к четырём слоям. Изображения пар можно оставить до завершения восстановления; в архивных данных они не используются. Запуск экспортёра заново создаст раздельные слои.
