# Мастерская рендеров продукции

Откройте `/freelancet-medved/materials/models/product-render-lab.html` на сервере разработки. Форма и пакетный экспорт вызывают одну функцию `mountProductRender({ product, preset, settings })`. Профили и общие значения находятся в `src/data/product-render-settings.js`.

| Назначение | Фон за стеклом | Тень | Композиция |
|---|---|---|---|
| Карточки товаров | Белый | Мягкая под продуктом | Один объект |
| Слайдер | Фон и стойка слайдера | От светильника, отдельный слой | Стакан и банка |
| Хиро категорий | Текущий плакат категории напитка | Мягкая под продуктом | Стакан, повышенное разрешение |

Настройки каждого назначения независимы. В форме шесть простых выборов: назначение, сорт, тень, фон, композиция и качество. Числовые параметры камеры, света, разрешения и тени находятся внутри готовых настроек, без отдельных полей в интерфейсе. Плакат хиро берётся из реестра `catalog-categories.js`. Свой фон и дополнительные настройки можно передать в JSON.

Фон просмотра не включается в PNG. Преломление — изображение за стеклом; отражения — окружающая световая сцена. Эти источники задаются отдельно. Стойка включается отдельной настройкой. На сайте используются статичные изображения; изменения мастерской сами по себе их не перегенерируют.

«Сохранить настройки назначения» сохраняет только выбранный профиль в текущем браузере. «Вернуть исходные настройки» сбрасывает его. Экспорт даёт PNG и JSON с полными настройками, рецептом, источниками и геометрией кадра. JSON можно открыть в форме или передать пакетному экспорту. Настройки в URL позволяют повторно открыть кадр. Локальное сохранение не изменяет исходные профили в репозитории.

Нулевые размеры PNG означают исходный размер буфера. Если указаны ширина и высота, слои помещаются в этот кадр с сохранением пропорций, без обрезки. Большой размер PNG сам по себе не добавляет деталей: отдельно задаются разрешение модели, масштаб рендера и разрешение фона преломления. Ширина и высота сцены определяют центральную обрезку фонового плаката. Для точного совпадения запечки с конкретным размещением на странице можно передать подготовленный фон в `background.refractionSource`; это значение сохраняется в JSON. Запечённый фон фиксирован и не перестраивается при изменении ширины страницы.

Пакетный экспорт одного продукта с исходным профилем:

Одиночные стаканы и банки центрируются по силуэту продукта без тени; все слои сдвигаются вместе, камера остаётся прежней. `output.subjectHeight` задаёт видимую высоту продукта в пикселях готового кадра, сохраняя его пропорции. Ноль оставляет обычное вписывание полного буфера. `node scripts/render-catalog-glasses.mjs` перерендеривает отдельные стаканы, сохраняя размеры холста и продукта из существующих PNG. Камера и остальные параметры сцены берутся из общего профиля в `src/data/product-render-settings.js`; промежуточные PNG и JSON создаются во временном каталоге и удаляются после экспорта. Переменная `MEDVED_RENDER_BACKUP` задаёт каталог резервных копий исходных изображений.

```sh
node scripts/render-products.mjs --preset card --product perry-williams
```

Повторный экспорт из скачанного JSON:

```sh
node scripts/render-products.mjs --settings /absolute/path/perry-williams-hero.json
```

Без `--product` или выбранного продукта в JSON экспортируются все сорта из `drink-presets.js`. По умолчанию результат сохраняется в `output/renders/products`: общий кадр, отдельные слои продукта и тени, JSON. `--directory` задаёт папку, `--format webp` включает WebP без потерь. `--origin http://localhost:5173/freelancet-medved` использует уже работающий сервер. Без `--origin` скрипт запускает свой сервер и закрывает его после экспорта.

`node scripts/render-product-slider.mjs` использует тот же пакетный экспорт с профилем `slider`, заменяет три пары слайдера и обновляет их координаты. Перед заменой файлов сайта проверьте и примите внешний вид через мастерскую.
