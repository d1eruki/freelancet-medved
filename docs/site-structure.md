# Структура сайта «МЁДВЕДЬ»

В структуру входят 6 основных страниц, 3 страницы категорий продукции и 2 юридические страницы. Всего — 11 веб-страниц.

## Основные страницы

1. Главная — `/`.
2. Каталог — `/katalog/`.
3. Производство — `/proizvodstvo/`.
4. О компании — `/o-kompanii/`.
5. HoReCa — `/horeca/`.
6. Контакты — `/kontakty/`.

## Категории продукции

1. Мид — `/katalog/medovuha/`.
2. Сидр — `/katalog/sidr/`.
3. Пуаре — `/katalog/puare/`.

## Юридические страницы и документ

1. Политика конфиденциальности — `/politika-konfidencialnosti/`.
2. Ограничение ответственности — `/disclaimer/`.
3. Реквизиты ООО «ФАРТ СПБ» — `/files/requisites_ooo_fart_spb_jan2018.pdf`.

## Служебная страница

Страница 404 показывается при запросе неизвестного адреса с HTTP-статусом 404. Она не входит в число 11 содержательных страниц и не включается в карту сайта.

Раздел «Где купить» временно скрыт: ссылки и маршрут отключены, прямой адрес возвращает 404. Исходные компоненты, данные партнёров и изображения сохранены для восстановления.
