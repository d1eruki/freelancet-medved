# Отличия оригинальной и клиентской версий

Оригинал — ветка `develope/original`, клиентская версия — `develope/client`.

| Название механики | Оригинал | Клиентская |
|---|---|---|
| Акцентный цвет сайта | Зелёный `#3d5a45` | Рыжий `#d9771a` |
| Фон слайдера на главной | Деревянные доски с логотипом и надписью «МЁДВЕДЬ», без декораций по краям | Деревянный фон с логотипом и надписью «МЁДВЕДЬ», резными полками, бутылками и бочками по краям |
| Продукция в слайдере на главной | Бокалы с логотипом медведя на основе изображений из блока «Три категории», с очищенными отражениями фона, и банки. Сохранены тени и раздельное движение: банка начинает первой, бокал — с задержкой 100 мс. | Только бокал с логотипом, без банки и раздельного движения двух объектов. |
| Бокалы в карточках категорий каталога | Бокалы медовухи, сидра и пуаре без логотипа | На всех трёх бокалах добавлен логотип медведя |
