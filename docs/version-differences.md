# Отличия оригинальной и клиентской версий

Оригинал — ветка `develope/original`, клиентская версия — `develope/client`.

| Название механики | Оригинал | Клиентская |
|---|---|---|
| Акцентный цвет сайта | Зелёный `#3d5a45` | Рыжий `#d9771a` |
| Продукция в слайдере на главной | Бокал с логотипом и банка. Двигаются раздельно: банка начинает первой, бокал — с задержкой 100 мс. | Только бокал с логотипом, без банки и раздельного движения двух объектов. |
| Бокалы в карточках категорий каталога | Бокалы медовухи, сидра и пуаре без логотипа | На всех трёх бокалах добавлен логотип медведя |
