# Текущая платформа сайта «МЁДВЕДЬ»

## Результат

Действующий сайт работает на **UMI.CMS версии 16**. Это серверная система управления контентом, установленная на хостинге, а не облачный конструктор сайтов.

## Обнаруженный стек

- CMS — `UMI.CMS 16`.
- Серверный язык — `PHP 7.0.33`.
- Веб-сервер — `nginx-reuseport/1.21.1`.
- Пользовательский шаблон — `/templates/medved/`.
- Собранные CSS и JavaScript шаблона — `/templates/medved/production/main.css` и `/templates/medved/production/main.js`.
- Сессии — стандартные PHP-сессии.
- Аналитика — Яндекс Метрика.

## Текущий хостинг

Сайт размещён у хостинг-провайдера **Beget**. Домен `medved.beer` направлен на IP-адрес `45.130.41.117`, принадлежащий сети Beget. Для домена используются DNS-серверы провайдера:

- `ns1.beget.com`;
- `ns2.beget.com`;
- `ns1.beget.pro`;
- `ns2.beget.pro`.

## Характер реализации

Сайт использует отдельный шаблон `medved`, поэтому его внешний вид разработан специально для проекта и не является стандартной темой конструктора. Контент, страницы, каталог продукции и новости хранятся и управляются средствами UMI.CMS, а отображение формируется сервером через шаблон сайта.

## Состояние платформы

Сайт работает на `PHP 7.0.33`. Поддержка ветки PHP 7.0 завершилась 10 января 2019 года, поэтому эта версия больше не получает обычные исправления безопасности.

Версия UMI.CMS 16 также не является актуальной веткой системы: в текущей документации UMI.CMS отдельно описываются изменения, появившиеся начиная с версии 21.
